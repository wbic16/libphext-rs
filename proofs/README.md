# libphext Lean proofs

Aeneas translation of libphext-rs to Lean 4, with the first kernel-checked
specifications. The generated model of the whole crate compiles under
`lake build` with no `sorry` anywhere in the generated code.

## Layout

- `Libphext/Code/Types.lean`, `Libphext/Code/Funs.lean` — generated by
  Aeneas from the Rust sources (do not edit by hand; regenerate instead).
- `Libphext/Code/FunsExternal.lean`, `Libphext/Code/TypesExternal.lean` —
  the external declarations Aeneas emits for items it does not model:
  standard-library string/slice/format items, the `xxh3_128` hash, and
  `explode`/`implode` (kept opaque because `HashMap` has no Lean model).
  These are axioms: results proved about the model hold relative to them.
- `Libphext/Properties/Basic.lean` — hand-written specifications, proved
  against the generated definitions (`advance_coordinate`,
  `default_coordinate`, `is_phext_break`).

## Building

1. Install the toolchain once: `scripts/install-proof-tools.sh`
   (OCaml + Charon + Aeneas + the Lean toolchain Aeneas pins).
2. Regenerate the model after Rust changes: `scripts/extract-proofs.sh`
   (Charon with `explode`/`implode` opaque, then Aeneas to Lean).
3. In `lakefile.lean`, the `aeneas` requirement is a path dependency on an
   Aeneas checkout's `backends/lean` directory; the committed path is the
   build node's checkout — repoint that one line to yours.
4. `cd proofs && lake update && lake build`
   (first build fetches the mathlib cache Aeneas's library depends on).

## Trust ledger (summary)

Proved by the Lean kernel: the generated definitions elaborate with no
errors and no `sorry`, and the three specifications in
`Properties/Basic.lean` check.

Trusted, not proved: the Charon and Aeneas translators themselves; the
Aeneas Lean standard-library models; the 62 external axioms in
`FunsExternal.lean` (including `xxhash_rust.xxh3.xxh3_128` as an
uninterpreted function — `checksum` is therefore verified only relative to
that signature, not to the real xxHash algorithm); and `explode`/`implode`
as opaque externals (their Rust behavior is covered by the crate's test
suite, not by Lean proofs).

The Rust sources were adjusted where the current Aeneas pin cannot
translate a construct (each change is behavior-identical and covered by
the full 58-test suite): `Vec::collect` became explicit push loops;
`str::split(char)`/`str::contains(char)` (the `Pattern` trait) became a
manual splitter and byte-slice checks; all char<->int casts became byte
constants (`SCROLL_BREAK_U8` and siblings); `Iterator::chain`/`skip`
became sequential/index loops; `split_on` returns owned `String`s; and
parameters named `phext` were renamed `input` because a local named
`phext` shadows the crate's namespace in generated Lean.
